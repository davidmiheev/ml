# Выходные данные

```
A
t i k
...
```

В первой строке выведите $A$ — количество выкаток, которые вы хотите совершить. В каждой из следующих $A$ строк выведите три числа $t$, $i$, $k$: в день $t$ на устройство $i$ выкатывается обновление $k$.

Строки можно выводить в любом порядке: результат дня не зависит от порядка строк внутри него.

Выкатка $(t,\ i,\ k)$ допустима, только если выполнены все условия:

- $0 \le t \le T-1$, $0 \le i \le S-1$, $0 \le k \le U-1$;
- $r_k \le t$ — обновление уже вышло;
- обновление $k$ не выкатывается на устройство $i$ повторно — ни в этот день, ни в какой-либо другой;
- в день $t$ на устройство $i$ не выкатывается другое обновление того же типа $c_k$ (обновления разных типов в один день на одно устройство выкатывать можно, в том числе все $C$ сразу);
- всего за все $T$ дней на устройство $i$ выкатывается не больше $u_i$ обновлений;
- для каждого дня $t$ суммарный размер всех выкаток этого дня не превосходит $G$;
- для каждого дня $t$ и каждого дома $m$ суммарный размер выкаток этого дня на устройства дома $m$ не превосходит $l_m$.

Отдельного ограничения на $A$ нет: из ограничения на количество выкаток каждого устройства следует, что в любом корректном ответе $A \le \sum_{i=0}^{S-1} u_i$.

Если нарушено хотя бы одно условие, ответ на этом тесте не зачитывается; частичных баллов за такой ответ нет.

# Входные данные

```
T S U C H G
l_0 l_1 ... l_{H-1}
d_0 u_0 w_{0,0} ... w_{0,C-1}
...
d_{S-1} u_{S-1} w_{S-1,0} ... w_{S-1,C-1}
c_0 s_0 h_0 r_0
...
c_{U-1} s_{U-1} h_{U-1} r_{U-1}
```

В первой строке — шесть чисел: $T$ — количество дней, $S$ — количество устройств, $U$ — количество обновлений, $C$ — количество типов моделей, $H$ — количество домов, $G$ — сколько мегабайт сервер может раздать за день.

Во второй строке — $H$ чисел $l_{m}$ — количество мегабайт, доступных для скачивания за день в доме $m$.

Далее $S$ строк описывают устройства, по $C+2$ числа в каждой; строка с номером $i$ (нумерация с нуля, в порядке появления) задаёт устройство $i$: номер дома $d_i$, максимальное количество выкаток $u_i$ за все $T$ дней и веса $w_{i0},\ \ldots,\ w_{i,C-1}$ важности каждого типа моделей.

Далее $U$ строк описывают обновления, по $4$ числа в каждой; строка с номером $k$ задаёт обновление $k$: тип модели $c_k$, размер в мегабайтах $s_k$, количество счастья $h_k$ и день релиза $r_k$.

Все числа целые, числа в одной строке разделены пробелом.

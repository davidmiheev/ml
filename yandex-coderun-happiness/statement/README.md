## Отправка решения

Перед отправкой решения, вам нужно создать репозиторий. В репозитории продублировано условие задач, и лежит директория solutions, в которой лежат шаблоны для решений, а также README.md, где описаны тест-кейсы. Ваша задача - написать решение на каждый тест-кейс. Решения могут быть как одинаковыми, так и разными под каждый тест. Решение для каждого кейса должно лежать строго внутри своего файла. Никакие другие файлы в решении учитываться не будут.
